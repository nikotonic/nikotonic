# nikotonic

Construyo sistemas para que agentes de IA piensen y trabajen como yo: cómo decido, cómo coordino a varios agentes y cómo convierto lo que funciona en reglas.

## Cómo trabajo

- **Primero la evidencia.** Una idea vale cuando se puede medir contra un caso real. Entregado no es aprobado.
- **Reglas que salen de correcciones.** Si un agente se equivoca, mi corrección se guarda tal cual y de ahí sale la nueva versión de la regla. Nada se borra: cada versión enlaza a la anterior.
- **Varios agentes, una sola fuente.** Claude construye, Codex revisa y Grok critica cuando lo llamo. Cada cambio va en su propia rama y su propio PR, y las decisiones las cierro yo.
- **Gastar poco.** Cada token y cada dólar cuentan: se lee solo lo necesario y se pregunta antes de gastar.

## En qué ando

- **criterio**: motor para emular una forma de pensar. Usa reglas versionadas, predicciones selladas antes de conocer la respuesta y un lenguaje compacto para comparar situaciones. *(privado por ahora)*
- **Romhacks de Super Mario World.**
